THIRIME SCHOOL APP  -  latest version

Everything that was already in the app is unchanged: marks, reports, parents'
reports with behaviour comments, attendance, timetable, print, teachers,
AI assistant, learners, Guidance & Counselling, logins and the cloud database.

NEW IN THIS VERSION
-------------------
PARENT DETAILS (tab: Parent Details)
  Parent or guardian name, relationship, two phone numbers, email and home area
  for each learner, with call and WhatsApp buttons. Add many at once from a list
  (Adm, Parent name, Phone, Relationship). The name and phone print on the
  parents' progress report. Behaviour comments stay in the Parents tab.

FEES (tab: Fees)
  The administrator sets the fee per term for each grade and records payments
  (receipt numbers are automatic). Also an Excel-style fee sheet: type brought
  forward, charged and amount paid, and the balance remaining updates as you
  type. Print the class list, a statement for each learner or a receipt.
  The parents' progress report shows the fee balance. "New school year"
  carries every balance forward. Teachers can see balances and print.

TERM OPENING (tab: Opening)
  Closing and opening dates, reporting time, a notice, and a requirements list
  for all grades and for each grade (a sample list is included, edit it).
  Tick what each learner brought. Print a class notice or one slip per learner
  with the fee balance, fees due and requirements.

CBC GRADING KEY (Setup, administrator)
  Set the levels, the lowest percentage and the points. Use one default key or
  give a learning area its own key. The key is shared through the cloud database.

GUIDANCE & COUNSELLING
  Each teacher opens their own private page and sees only their own notes.
  The administrator can open every teacher's page. References are shared and
  start with a list of Kenyan helplines and laws (confirm numbers before use).
  A new Share view exports and imports references and gives an anonymised
  findings summary. The administrator can change the password in Setup.

EDIT TIMETABLES (tab: Edit Timetables)
  Class, Master and Personal timetables can be edited in place and always match.
  Personal pages add or remove a teacher's lessons and keep daily notes.

SETUP
  Setup now shows the administrator everything and teachers only My account.

PDF
  Every list download is now a PDF made inside the app, so it works offline.
  Backup files stay as data files.

INSTALL AND OFFLINE
  The app works offline after the first visit and fits phones, tablets and
  computers. To install it with its own icon, upload this folder to a free web
  host (Netlify Drop, GitHub Pages or Cloudflare Pages), open the address in
  Chrome and tap Install app. On iPhone or iPad use Safari, Share, Add to Home
  Screen. Thirime_School_App_single_file.html works offline without a host but
  cannot be installed.

LOGIN
  Username is the TSC number and password is the ID number. A starting
  administrator account is created the first time the app opens on a device with
  no accounts. Change it in Setup (Teacher logins).

WHERE DATA LIVES
  Fees, term-opening lists, counselling notes and personal timetable notes stay
  on the device and are not sent to the cloud database. Parent details, the
  grading key and timetables follow the existing cloud sync. Download a backup
  file often.


---------------------------------------------------------------
UPDATES IN THIS VERSION
---------------------------------------------------------------
TEACHER LOGINS (Setup, administrator)
  Add one teacher at a time or paste many. Make a teacher an administrator, or
  make an administrator a teacher, with one tap. Remove a teacher (you are asked
  to confirm). You cannot remove or demote your own login.

MASTER TIMETABLE
  Only administrators can edit the master timetable. Everyone else sees it view
  only. Administrators can also switch off teachers' edits to the class and
  personal timetables (Edit Timetables, tick box at the top). Teachers can always
  keep personal notes.

AUTOMATIC SIGN-OUT
  The app signs a person out after 10 minutes of not being used. A warning with a
  Stay signed in button appears one minute before. Guidance & Counselling locks
  again after 5 minutes.

LEARNER UNIQUE CODE (UPI)
  Add a learner with admission number, unique code and name, or paste a list as
  Adm, Full name, Unique code. A unique code can belong to only one learner. Edit
  a learner's details with the Edit button. The code appears in the learner list,
  parent details, progress reports, fee statements, opening slips and PDF lists.

INSTALL ON PHONE AND COMPUTER
  New icon, install support for Android, iPhone, Windows, Mac and Linux, and
  screenshots for the install window. See INSTALL_GUIDE.html in the zip.
